# NetPractice — 42

Proyecto del currículo de **42** centrado en fundamentos de **redes** y **subnetting** mediante ejercicios prácticos.

---

## ✅ Objetivos pedagógicos
Este proyecto busca desarrollar competencias en:
- Comprensión de **redes IP** y **subredes**.
- **Subnetting** y cálculo de máscaras.
- Direccionamiento de red y **rutas estáticas**.
- Interpretación de **topologías** y resolución de problemas de conectividad.
- Pensamiento lógico aplicado a arquitectura de red.

---

## 🧩 Contenido
NetPractice se trabaja en una plataforma con niveles que simulan redes reales.  
En cada nivel se debe configurar **IPs, máscaras, gateways y rutas** para asegurar conectividad total.

---

## 🧠 Notas
El proyecto fortalece la capacidad de análisis y la comprensión de cómo se comunican sistemas en red, base fundamental para sistemas distribuidos, servidores y DevOps.
